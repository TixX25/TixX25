### 🚀 Featured Engineering Projects

1. 🧠 **[BCI-EEG-Thought-Digits-Decoding](#):** Multiclass decoding of 10 imagined MNIST digits from massive EEG recordings ($N=18,000$ trials, 2.55 GB) using a Python streaming pipeline, zero-phase Butterworth + MAD Winsorizing tunnel, coherent ERP averaging ($K=8$), 50D spectral-spatial features (Welch PSD, Hjorth, DASM), and optimized MLP (`patternnet`, 100% 5-Fold CV in Cut3 / 53.03% blind test in Full with $8.23\text{ }\mu\text{s}$ latency).
2. 🤖 **[Differential-Robot-EKF-Navigation](#):** 2D stochastic pose estimation fusing quadrature encoders and MPU6050 IMU via Extended Kalman Filter (EKF) on ESP32, featuring potential-field obstacle avoidance, vector wall-following, and a real-time MATLAB telemetry GUI.
3. 🛸 **[Autonomous-Blimp-SystemID-PID](#):** Experimental parametric identification via Wi-Fi/UDP telemetry and discrete-time pole-placement PID control (difference equations with anti-windup) for altitude and yaw regulation on an ESP32-S3 micro-blimp.
4. 🦾 **[OpenBotv2-6DOF-Kinematics-Workspace](#):** Analytical and numerical forward/inverse kinematics (Denavit-Hartenberg & wrist decoupling with $10^{-16}\text{ m}$ accuracy) and 3D Monte Carlo Alpha-Shape workspace mapping in MATLAB.
5. 🔌 **[ESP32-Multipurpose-PCB-Embedded-Suite](#):** Dual-layer development PCB designed in Altium Designer supporting a coaxial 3D-printed ultrasonic radar (AS5600 12-bit I2C encoder + flicker-free TFT), a Blynk IoT 2-DOF closed-loop turret vehicle, and a hardware-timer RTTTL synthesizer.
